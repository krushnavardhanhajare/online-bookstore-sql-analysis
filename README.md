# 📚 Online Bookstore SQL Analysis

**A SQL Data Analytics Project | MySQL | Business Insights**

## 📌 Project Overview

This project explores an online bookstore database to analyze book inventory, customer information, and order transactions using SQL. The objective is to practice SQL querying techniques and extract meaningful insights that support data-driven business decisions.

## 🎯 Project Objectives

- Analyze book inventory, genres, authors, and pricing.
- Explore customer locations and ordering patterns.
- Examine sales quantities and transaction amounts.
- Identify frequently ordered books and high-spending customers.
- Apply SQL techniques to answer practical business questions.

## 🗂️ Dataset Description

The project uses three datasets:

| Dataset | Description |
|---|---|
| `Books.csv` | Book titles, authors, genres, prices, publication years, and stock |
| `Customers.csv` | Customer details and geographical information |
| `Orders.csv` | Order dates, book IDs, quantities, and transaction amounts |

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Query Language:** SQL
- **Techniques:** Filtering, Sorting, Aggregate Functions, JOINs, GROUP BY, HAVING, and Subqueries
- **Version Control:** GitHub

## 🔍 Key Business Questions

- Which books belong to a particular genre?
- Which books were published after a specified year?
- How much stock is available across the bookstore?
- Which genres generate the highest sales quantities?
- Which customers place multiple orders?
- Which books are ordered most frequently?
- Which customers spend the most?
- How do book prices vary across genres and authors?
